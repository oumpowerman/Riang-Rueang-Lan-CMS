# แผนการปรับโฉมแผงค้นหาและตัวกรองตอน (EpisodeFilterControls)

ปรับโครงสร้างแผงควบคุมการค้นหาและตัวกรองในหน้าคลังตอนหลักใหม่ทั้งหมด เพื่อแก้ปัญหาปุ่มเบียดกันจนตัดขึ้นบรรทัดใหม่ไม่สมมาตร ช่องค้นหาแคบจนข้อความขาด และกรอบปุ่มย่อยซ้อนกันมากเกินไป โดยใช้โครงสร้าง 2 แถวที่ชัดเจนในโทนสีพาสเทลเอิร์ธโทนสว่าง

---

## 1. โครงสร้างการจัดวางแบบ 2 แถวสมมาตร (2-Tier Clean Toolbar)

### แถวที่ 1: ค้นหาหลัก + สรุปจำนวนตอน + สลับมุมมอง
- **ช่องค้นหาเต็มความกว้าง (Full-Width Flex Search)**: ขยายช่องค้นหาให้ใช้พื้นที่หลักทางด้านซ้ายอย่างเต็มที่ เพื่อให้เห็นคำแนะนำการค้นหาครบถ้วน พิมพ์ค้นหารหัส EP, ชื่อตอน, หมวดย่อย, ชื่อไฟล์ หรือรหัสฟุตเทจได้สะดวก พร้อมปุ่มล้างคำค้นหาทันที
- **ปุ่มตัวกรองละเอียดตามบริบท (Contextual Sub-Filter Trigger)**:
  - เมื่อผู้ใช้ **เลือกซีรีส์หลักแล้ว** ระบบจะแสดงตัวเลือก **หมวดย่อย (Subcategory)** และ **รูปแบบตอน (รวมหลากประเด็น / เจาะจงหมวดย่อย)** อย่างเป็นระเบียบโดยไม่แย่งพื้นที่ค้นหา
  - หากยังไม่ได้เลือกซีรีส์หลัก จะซ่อนไว้ภายใต้ปุ่ม **"ตัวกรองเพิ่มเติม"** ที่กดเปิด-ปิดได้ เพื่อไม่ให้หน้าจอดูรกตาในมุมมองเริ่มต้น
- **สรุปผลลัพธ์และปุ่มสลับมุมมอง (Right Utility Zone)**: จัดวางตัวเลขจำนวนตอนที่พบ (`พบ X / Y ตอน`) แบบข้อความสะอาดตาคู่กับปุ่มสลับมุมมอง **การ์ด / ตาราง** ชิดขวาอย่างสมดุล

---

### แถวที่ 2: แถบแท็บสถานะขั้นตอนการทำงาน + การเรียงลำดับ
- **แถบปุ่มแท็บสถานะพร้อมตัวเลขจำนวนตอน (Interactive Workflow Stage Tabs)**:
  - เปลี่ยนจากเมนู Dropdown แบบเดิมเป็นแถบปุ่มแท็บกดสลับได้ทันทีในคลิกเดียว:
    1. **ทั้งหมด** (พร้อมจำนวนตอนรวมตามเงื่อนไขที่กรองอยู่)
    2. **1. ผสมฟุตเทจ** (พร้อมจำนวนตอน)
    3. **2. เขียนบทมาสคอต** (พร้อมจำนวนตอน)
    4. **3. ตัดต่อวิดีโอ** (พร้อมจำนวนตอน)
    5. **4. เผยแพร่แล้ว** (พร้อมจำนวนตอน)
  - ใช้สีพาสเทลเอิร์ธโทนสว่างแยกสถานะที่กำลังเลือกอย่างนุ่มนวล สบายตา และเห็นภาพรวมงานคงค้างในแต่ละขั้นตอนได้ทันที
- **ตัวเลือกการเรียงลำดับ (Clean Sort Selector)**: จัดวางชิดขวาของแถวที่ 2 คู่กับปุ่ม **"ล้างตัวกรอง"** ที่จะปรากฏขึ้นเฉพาะเมื่อมีการใช้งานตัวกรองเท่านั้น

---

## 2. แถบสรุปตัวกรองที่ใช้งานอยู่ (Streamlined Active Filter Bar)
- แสดงเฉพาะเมื่อมีการกรองข้อมูล (เช่น เลือกกลุ่ม, ซีรีส์, หมวดย่อย, รูปแบบตอน หรือคำค้นหา)
- ลดความหนาของเส้นขอบป้ายกำกับ ให้เป็นป้ายสีพาสเทลอ่อนพร้อมปุ่มกากบาท (`×`) กดยกเลิกทีละรายการ หรือกดปุ่ม **"ล้างตัวกรองทั้งหมด"** ได้ในคลิกเดียว

---

## 3. การคำนวณจำนวนตอนแบบ Real-Time (Scalable Count Metrics)
- เพิ่มการคำนวณจำนวนตอนแยกตามสถานะขั้นตอนการทำงานทั้ง 4 ขั้นตอนแบบ O(1) สอดคล้องกับกลุ่มหมวดหมู่ ซีรีส์ หมวดย่อย และคำค้นหาที่เลือกอยู่ เพื่อให้ตัวเลขบนแท็บสถานะแม่นยำเสมอแม้มีคลิปในคลังมากกว่า 1,000 ตอน
