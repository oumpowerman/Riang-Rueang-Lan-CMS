# ปรับปรุง Animation การกางหมวดหมู่และขยายคอลัมน์ 3 ชั้น (หน้าจัดคลิป 5 อันดับ)

ยกระดับประสบการณ์ใช้งานในส่วน **เลือกหมวดและแท็ก 3 ชั้น (ขั้นที่ 1)** ของหน้า **จัดคลิป 5 อันดับ** ให้การกาง/พับหมวดย่อยและคอลัมน์แต่ละ Tier ลื่นไหลนุ่มนวลสบายตา พร้อมปุ่มขยายความกว้างคอลัมน์เมื่อต้องค้นหาและเลือกแท็กจำนวนมาก

---

### User Review & Critical Decisions

> [!IMPORTANT]
> สรุปแนวทางที่ยืนยันแล้วจากการตอบคำถาม เพื่อใช้เป็นมาตรฐานหลักในการพัฒนา:

- **อารมณ์ของ Animation (Confirmed)**: เน้น **นุ่มนวลลื่นไหล เปิดปิดสมูทสบายตา** ด้วยจังหวะการชะลอตัวแบบ Cubic-Bezier ที่นิ่มนวล (ระยะเวลา ~260–320ms) ไม่กระชากหรือเด้งเกินความจำเป็น
- **จังหวะการกางทั้งคอลัมน์ (Confirmed)**: เมื่อกดปุ่ม **กาง / พับ** ที่หัวคอลัมน์ Tier จะ **ไล่เรียงเปิดทีละหมวดต่อเนื่องแบบ Cascade** (หน่วงเวลาทีละหมวดเล็กน้อยอย่างเป็นธรรมชาติ) ทำให้สายตาไล่ตามรายการแท็กได้ง่าย
- **ขอบเขตการขยายคอลัมน์ (Confirmed)**: รองรับทั้ง **Animation กาง/พับหมวดย่อยภายใน** และ **เพิ่มปุ่มขยายความกว้างคอลัมน์ Tier** เพื่อให้โฟกัสเลือกแท็กในชั้นที่มีรายการเยอะได้เต็มตา

---

### 1. Overview & Core Concept

- **What It Does**:
  1. เพิ่ม Animation เปิด/ปิดแบบ Smooth Accordion ให้ทุกกล่องหมวดย่อยภายในคอลัมน์ Tier 1, Tier 2 และ Tier 3 ทั้งการคลิกเปิดทีละหมวด และการกดปุ่ม "กางทั้งหมด / พับทั้งหมด" บนหัวคอลัมน์
  2. เพิ่มระบบขยายความกว้างคอลัมน์ระดับ Tier บนหน้าจอ Desktop (`lg:` ขึ้นไป) โดยเมื่อกดปุ่มขยายที่หัวคอลัมน์ใด คอลัมน์นั้นจะกางกว้างออกอย่างนุ่มนวล พร้อมแสดงแท็กแบบกระจายพื้นที่เต็มความกว้าง ส่วนอีก 2 คอลัมน์ที่เหลือจะหดเป็นแถบแคบด้านข้าง (Compact Rail) ที่สามารถคลิกสลับกลับหรือสลับไปขยายคอลัมน์อื่นได้ทันที
- **Target Audience / Persona**: ทีมตัดต่อและจัดชุดคลิป 5 อันดับ ที่ต้องเปิดดูหมวดหมู่ย่อยและผสมแท็กข้าม 3 ชั้นอยู่เป็นประจำ
- **Key Value**: ลดความแข็งกระด้างของการกระพริบเปิด-ปิดทันที ช่วยให้สายตาจับตำแหน่งหมวดหมู่ได้ต่อเนื่อง และแก้ปัญหาพื้นที่แคบเวลาต้องเลือกแท็กใน Tier ที่มีหมวดย่อยและแท็กจำนวนมาก

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **กาง/พับหมวดย่อยรายหมวด**: ผู้ใช้คลิกที่หัวหมวดย่อย -> ไอคอนลูกศรหมุน 90 องศาอย่างนุ่มนวล -> กรอบเนื้อหาค่อยๆ ยืดความสูงลงมาพร้อมแท็กภายในที่ปรากฏขึ้นอย่างนิ่มนวล และเมื่อกดปิดจะหดกลับอย่างสมูท
  2. **กาง/พับทั้งคอลัมน์ (Cascade)**: ผู้ใช้กดปุ่ม **กาง** บนหัวคอลัมน์ Tier 1/2/3 -> หมวดย่อยทั้งหมดในคอลัมน์นั้นทยอยกางเปิดไล่เรียงจากบนลงล่างต่อเนื่อง (Staggered Cascade) ส่วนตอนกด **พับ** จะหุบเก็บรวมกันอย่างนุ่มนวล
  3. **ขยายความกว้างคอลัมน์ Tier**: ผู้ใช้กดปุ่มขยายมุมขวาบนของหัวคอลัมน์ Tier -> คอลัมน์นั้นขยับขยายกินพื้นที่หลักของแถว (Tag แสดงผลเรียงตัวอ่านง่ายขึ้น) ส่วนอีก 2 Tier จะย่อตัวเป็นแถบข้างแบบกะทัดรัด (แสดงชื่อ Tier, จำนวนแท็ก และปุ่มกางกลับ) -> กดปุ่มย่ออีกครั้งเพื่อกลับสู่ 3 คอลัมน์สมมาตรตามปกติ
- **Visual Identity & Theme**:
  - คงโทนสี **Light Pastel** ประจำแต่ละ Tier อย่างครบถ้วน (Tier 1 ฟ้าพาสเทล, Tier 2 เหลืองครีมพาสเทล, Tier 3 เขียวพาสเทล บนพื้นหลังครีมอุ่น `#FAF8F5`)
  - เส้นขอบบางเบา (1px Hairline Border) และตัวเลขสถิติแบบ Monospace Tabular (`tabular-nums`) เพื่อความนิ่งของเลย์เอาต์ขณะแอนิเมชันทำงาน
  - คง **Slim Custom Scrollbar** (`scrollbar-thin`) ภายในคอลัมน์เพื่อให้ดูสะอาดตาและไม่กินพื้นที่
- **Interactive Feedback & Motion**:
  - **Accordion Curve**: ใช้ Custom Cubic-Bezier `[0.22, 1, 0.36, 1]` ระยะเวลา `0.28s` สำหรับเปิด และ `0.22s` สำหรับปิด เพื่อความนุ่มนวลและไม่อืด
  - **Cascade Delay**: คำนวณค่าหน่วงเวลาแบบจำกัดเพดาน (เช่น ไล่ระดับ `35ms` ต่อหมวด สูงสุดไม่เกิน `220ms`) เพื่อให้แม้มี 15+ หมวดย่อยก็จะยังเปิดจบครบถ้วนทันใจภายในครึ่งวินาที
  - **Column Width Transition**: ใช้ `layout` transition ของ Motion ควบคู่กับ CSS Flex Transition สำหรับพื้นที่คอลัมน์ และซ่อน/แสดงเนื้อหาภายใน Compact Rail ด้วยการจางสลับ (Cross-fade) ไม่ให้ตัวอักษรบีบเบี้ยวระหว่างกำลังขยาย
  - **Reduced Motion Support**: รองรับ `useReducedMotion()` เพื่อให้ผู้ที่ปิด Animation ในระบบปฏิบัติการยังคงใช้งานได้รวดเร็วโดยไม่กระตุก

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: การทำ Cascade เฉพาะจังหวะกดปุ่ม "กาง" ทั้งคอลัมน์ vs หน่วงเวลาตลอด**
  - *Chosen Approach*: แยกโหมดแอนิเมชันระหว่าง **เปิดรายหมวด (Instant Smooth, delay = 0)** กับ **เปิดทั้งคอลัมน์ (Staggered Cascade, delay ตามลำดับหมวด)** และเวลา **พับทั้งหมด** ให้ปิดพร้อมกันเพื่อความกระชับ
  - *Why*: หากคลิกเปิดหมวดเดียวแล้วมี delay จะรู้สึกหน่วงโดยไม่จำเป็น แต่เมื่อกดกางทั้งคอลัมน์ การไล่เปิดทีละชั้นจะช่วยให้สายตาโฟกัสได้ชัดเจนและดูพรีเมียม
  - *Alternatives Considered*: ใส่ Stagger เฉพาะตอนเปิดครั้งแรกหรือทุกครั้ง — ถูกตัดออกเพราะทำให้การเปิดหมวดล่างๆ แบบรายตัวดูช้าลง
- **Decision 2: พฤติกรรมของอีก 2 คอลัมน์เมื่อกดขยายความกว้าง 1 คอลัมน์**
  - *Chosen Approach*: ใช้รูปแบบ **Expanded Column + 2 Compact Side Rails** บนจอใหญ่ (`lg:` ขึ้นไป) คล้ายแนวทางของหน้า Studio แท็ก 3 ชั้น และซ่อนปุ่มขยายคอลัมน์บนจอมือถือ (เพราะมือถือเรียงเป็นแนวตั้ง 1 คอลัมน์อยู่แล้ว)
  - *Why*: ผู้ใช้ยังเห็นสถานะของอีก 2 Tier (เช่น เห็นว่าเลือกแท็กหลักหรือผสมแท็กไว้กี่ตัวแล้ว) และสลับไปขยาย Tier ถัดไปได้ในคลิกเดียวโดยไม่ต้องหุบกลับก่อน
  - *Alternatives Considered*: ซ่อนอีก 2 คอลัมน์ทิ้งไปเลย — ถูกตัดออกเพราะเวลาผสมแท็กข้าม Tier ผู้ใช้จะมองไม่เห็นบริบทของชั้นอื่น
- **Decision 3: การแบ่งโครงสร้างโค้ด (Enterprise Modularization)**
  - *Chosen Approach*: แยกส่วนคอลัมน์ Tier และกรอบหมวดย่อยที่กำลังจะมีโค้ดแอนิเมชันเพิ่มเข้ามา ออกเป็น Sub-components เฉพาะทาง เพื่อให้ทุกไฟล์มีขนาดกะทัดรัด อ่านง่าย และต่ำกว่าเกณฑ์ 800 บรรทัดอย่างชัดเจน

### 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Step 1 Accordion Container (Active Target Bar + Search + Tier Grid)      │
│  ├── State: expandedSubKeys, cascadeOriginTier, expandedTierColumn       │
│  └── Layout Grid / Flex Container (Desktop: 3 Columns <-> 1 Wide + Rails)│
│        │                                                                 │
│        ├──▶ Tier Column Container [Tier 1 | Tier 2 | Tier 3]             │
│        │     ├── Compact Rail Mode (เมื่อ Tier อื่นกำลังถูกขยายอยู่)     │
│        │     └── Full / Expanded Mode                                    │
│        │           ├── Header: Badge + Title + [กาง/พับ] + [ขยายคอลัมน์] │
│        │           └── Scrollable Body (scrollbar-thin)                  │
│        │                 └── Sub-Category Accordion Item (per group)     │
│        │                       ├── Trigger Row (Animated Chevron + Counts│
│        │                       └── AnimatePresence + motion.div          │
│        │                             └── Smooth Height + Opacity + Slide │
│        │                                   └── Tag Chips (Primary/Facet) │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `expandedSubKeys`: เก็บสถานะเปิด/ปิดของแต่ละหมวดย่อยในรูปแบบ `${tier}__${subCategory}` (คงโครงสร้างเดิม)
  - `cascadeGroupIndex` / `isCascadeAnimating`: State ชั่วคราวหรือ Reference ที่ระบุว่าคำสั่งเปิดล่าสุดมาจากการกดปุ่ม "กางทั้งหมด" ใน Tier ใด เพื่อจ่าย `transition.delay` ให้กับหมวดย่อยแต่ละอันอย่างถูกต้อง โดยไม่กระทบตอนคลิกเปิดทีละหมวดหรือตอนพิมพ์ค้นหา
  - `expandedTierColumn`: State (`null | 1 | 2 | 3`) ควบคุมว่ากำลังขยายความกว้างคอลัมน์ไหนอยู่
- **Interactive Component & State Mapping**:
  - **กดหัวหมวดย่อย**: สลับค่า `expandedSubKeys[subKey]` -> ใช้ `delay: 0` -> `AnimatePresence` ขับเคลื่อนความสูง `0 <-> auto` พร้อมหมุน `motion.span` ของลูกศร `0deg <-> -90deg`
  - **กดปุ่ม กาง/พับ ที่หัวคอลัมน์ Tier**: กำหนดโหมด Cascade ชั่วคราวสำหรับ Tier นั้นแล้วอัปเดต `expandedSubKeys` ทุกหมวดใน Tier -> หมวดย่อยทยอยเปิดเรียงลำดับด้วยความเร็วคงที่และสมูท -> ปุ่มบนหัวคอลัมน์สลับไอคอน/ข้อความระหว่าง `กาง` กับ `พับ`
  - **กดปุ่ม ขยาย/ย่อ คอลัมน์ Tier**: สลับ `expandedTierColumn` ระหว่าง `tier` กับ `null` -> คอลัมน์ที่เลือกปรับความกว้างเต็มพื้นที่และเปลี่ยนการจัดวางแท็กให้โปร่งขึ้น ขณะที่คอลัมน์อื่นสลับเข้าสู่โหมด Compact Rail ที่คลิกสลับได้ทันที
  - **พิมพ์คำค้นหา (`step1SearchQuery`)**: เปิดหมวดย่อยที่มีผลลัพธ์โดยอัตโนมัติ (แบบ `delay: 0` เพื่อไม่ให้หน่วงการพิมพ์) และปรับแอนิเมชันให้ตอบสนองทันที
