# ปรับปรุง UI และสถานะปุ่มซิงก์ข้อมูลบน Navbar (Cloud Sync Status Button Redesign)

ปรับปรุงการแสดงผลของปุ่มสถานะการซิงก์ข้อมูลบน Navbar (ทั้งหน้าจอ Desktop และ Mobile) เพื่อแก้ปัญหาที่ปุ่มแสดงคำว่า "ซิงก์" พร้อมไอคอนรีเฟรชสีเทาตลอดเวลา จนทำให้ผู้ใช้เข้าใจผิดว่าระบบยังไม่ได้ซิงก์ โดยเปลี่ยนมาแสดงข้อความ **"ซิงก์แล้ว"** พร้อมไอคอนคลาวด์สีเขียวพาสเทลที่ให้ความมั่นใจและชัดเจนทันทีที่มอง

---

## User Review & Critical Decisions

> [!IMPORTANT]
> สรุปตัวเลือกที่ผู้ใช้ยืนยันแล้วจากการสอบถามใน Phase 1:

- **การแสดงผลเมื่อข้อมูลตรงกับ Cloud สมบูรณ์แล้ว**: แสดงข้อความ **"ซิงก์แล้ว"** พร้อมไอคอนคลาวด์สีเขียวพาสเทล (`text-emerald-700 bg-emerald-50/70 border-emerald-200/80`)
- **การทำงานเมื่อคลิกที่ปุ่ม**: คลิกเพื่อเปิด **"ศูนย์ซิงก์ข้อมูล Cloud"** เพื่อตรวจสอบยอดและเลือกระดับการรีเฟรชตามปกติ

---

## 1. Overview & Core Concept

- **ปัญหาเดิม**: เมื่อระบบอยู่ในสถานะปกติที่ซิงก์ข้อมูลครบถ้วนแล้ว (`status === 'synced'`) ปุ่มเดิมแสดงคำว่า `"ซิงก์"` ซึ่งเป็นคำกริยา (Call to Action) คู่กับไอคอนลูกศรหมุนวนสีเทา (`RefreshCw`) ทำให้ผู้ใช้รู้สึกตลอดเวลาว่าระบบกำลังบอกให้กดซิงก์เพราะข้อมูลยังไม่ซิงก์
- **แนวทางใหม่**: ปรับปรุง State Machine ของปุ่มให้เป็น **Status Indicator + Action Trigger** ที่ชัดเจน:
  - เมื่อข้อมูลตรงกันสมบูรณ์: แสดงสถานะเชิงยืนยัน (Affirmative Synced) ว่า **"ซิงก์แล้ว"** โทนสีเขียวพาสเทลสบายตา
  - เมื่อคลิก: ยังคงทำหน้าที่เป็นทางลัดเปิดศูนย์ซิงก์ข้อมูล Cloud เพื่อดูรายละเอียดและสั่งงานได้ตลอดเวลา

## 2. User Experience & Visual Design

### การแสดงผลแยกตามสถานะ (Comprehensive Sync States)

| สถานะระบบ | ข้อความบนปุ่ม (Desktop) | ไอคอน | โทนสี (Light Pastel) | รูปแบบ Compact (Mobile) |
| :--- | :--- | :--- | :--- | :--- |
| **ซิงก์เรียบร้อย (Synced)** | **ซิงก์แล้ว** | `Cloud` + ติ๊กถูกเขียว หรือ `CheckCircle2` | เขียวพาสเทลอ่อน (`bg-emerald-50/80 text-emerald-800 border-emerald-200/90`) | ไอคอนคลาวด์สีเขียวพาสเทล + จุดเขียว |
| **กำลังซิงก์ (Syncing)** | **กำลังซิงก์...** | `RefreshCw` หมุนอนิเมชัน | ครามพาสเทล (`bg-indigo-50 text-indigo-700 border-indigo-200`) | ไอคอนรีเฟรชหมุนวน |
| **มีคิวค้างส่ง (Pending Outbox)** | **รอส่ง N** | `UploadCloud` | ส้มพาสเทล (`bg-amber-50 text-amber-900 border-amber-200`) | ไอคอนคลาวด์อัปโหลด + ตัวเลขคิว |
| **พบยอดไม่ตรง (Drift Detected)** | **ยอดไม่ตรง** | `AlertTriangle` | เหลืองส้มพาสเทล (`bg-amber-50 text-amber-800 border-amber-200`) | ไอคอนสามเหลี่ยมเตือนสีส้ม |
| **ออฟไลน์ / โควตาเต็ม** | **ออฟไลน์** / **เต็มโควตา** | `CloudOff` | แดงพาสเทลอ่อน (`bg-rose-50 text-rose-800 border-rose-200`) | ไอคอนคลาวด์มีขีดฆ่าสีแดง |

### รายละเอียด Tooltip และการตอบสนอง
- มี Tooltip แสดงรายละเอียดเวลาซิงก์ล่าสุดอย่างสุภาพ เช่น `"ข้อมูลในเครื่องตรงกับ Cloud สมบูรณ์ (ซิงก์ล่าสุด 03:15 น.) — คลิกเพื่อดูศูนย์ซิงก์"`
- ขนาดปุ่มเป็นไปตามมาตรฐานการกด (Touch Target $\ge 36\text{px}$ บน Mobile, Single-line `whitespace-nowrap shrink-0`)

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: เปลี่ยนคำจาก "ซิงก์" เป็น "ซิงก์แล้ว" ในสถานะปกติ**
  - *เหตุผล*: คำว่า "ซิงก์" สื่อถึงคำสั่ง (Imperative) ที่ชวนให้กดซ้ำ ส่วน "ซิงก์แล้ว" สื่อถึงสถานะปัจจุบันที่สำเร็จแล้ว (State Descriptor) ทำให้ผู้ใช้ไม่สับสน
- **Decision 2: ใช้ไอคอนคลาวด์สีเขียวพาสเทลแทนไอคอนรีเฟรชสีเทา**
  - *เหตุผล*: ไอคอนรีเฟรชลูกศรหมุนวนสื่อถึงการโหลดซ้ำหรือการมีข้อผิดพลาด การเปลี่ยนเป็นไอคอนคลาวด์พร้อมสัญลักษณ์สถานะสีเขียวทำให้สะท้อนการเชื่อมต่อ Cloud ได้ตรงจุด
