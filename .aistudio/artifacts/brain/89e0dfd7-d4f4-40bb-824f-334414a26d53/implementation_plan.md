# ปรับโครงสร้างหน้าคลังคลิปหลัก (Master Archive Clarity & Hierarchy)

จัดระเบียบหน้า **คลังคลิปหลัก (Master Archive)** ใหม่เพื่อลดความสับสนจากแถบเครื่องมือและแผงตัวกรองที่ซ้อนกัน 5 ชั้น โดยรวมปุ่มจัดการทั้งหมดไว้ในเมนูเดียว ย่อการ์ดสถิติให้บางลง เน้นสวิตช์สลับมุมมองหลักให้ชัด และย้ายแผง **สรุป 55 รายการ** กับ **แท็ก 3 ชั้น** ไปเปิดใช้งานจากแถบค้นหาเดียวเพื่อดึงรายการคลิปขึ้นมาอยู่ในระดับสายตาหลักทันที

## User Review & Critical Decisions

> [!IMPORTANT]
> แผนนี้อ้างอิงจากการตัดสินใจที่คุณยืนยันครบทั้ง 3 ข้อแล้ว สามารถตรวจทานลำดับหน้าจอใหม่และกด **Proceed** เพื่อเริ่มดำเนินการได้เลยครับ

- **รวม 3 ปุ่มจัดการเข้าเมนูเดียว (`จัดการคลัง`)**: ยุบปุ่ม **จัดหมวดคลังคลิป**, **ปรับ Template สุดฮา!**, และ **เพิ่มคลังคลิปสู่ Kontent OS** จากแถบปุ่ม 2 แถวบนส่วนหัว ให้เหลือปุ่มเมนูดรอปดาวน์ **`จัดการคลัง`** เพียงปุ่มเดียวทั้งบน Desktop และ Mobile (พร้อมตัวเลขแจ้งเตือนจำนวนตอนที่รอปรับ Template)
- **รวมปุ่มเปิด "สรุป 55 รายการ" และ "แท็ก 3 ชั้น" ไว้ในแถบค้นหาเดียว**: ถอดแถบแบนเนอร์แบบพับ 2 อันที่คั่นกลางหน้าออกถาวร แล้วนำไปวางเป็นปุ่มเปิดใช้เฉพาะเมื่อต้องการ (**`สรุป 55 รายการ`** และ **`แท็ก 3 ชั้น`**) ภายในแถบค้นหาหลักเพียงแถบเดียว
- **ส่วนหัวกระชับ + การ์ดสถิติ 4 ใบแบบบาง**: ตัดคำอธิบายย่อยยาว 2 บรรทัดใต้หัวข้อออก เน้นสวิตช์สลับมุมมอง **`มุมมองรายตอน`** ⇄ **`ชั้นวางรายการ 5 อันดับ`** ให้ชัดเจนในแถวเดียวกับชื่อหน้า และลดความสูงของการ์ดสถิติ 4 ใบให้บางและอ่านง่าย

---

## 1. Overview & Core Concept

- **What It Does**: ลดความสูงของโซนควบคุมด้านบนหน้าคลังคลิปหลักจากเดิม 5 กล่องซ้อน (~650px) ให้เหลือ **3 ชั้นที่เข้าใจได้ในเสี้ยววินาที** (1. ส่วนหัว + สถิติแบบบาง, 2. ตัวเลือกหมวดและรายการ 5 อันดับ, 3. แถบค้นหารวมคำสั่ง + รายการคลิปหลัก)
- **Target Audience / Persona**: ทีมโปรดักชันและแอดมินที่เข้าหน้าคลังคลิปหลักเพื่อค้นหาตอน แก้ไขรายละเอียด ตรวจความครบถ้วน หรือสลับไปดูชั้นวางรายการ 5 อันดับ
- **Key Value**: ลดอาการ "งง" จากปุ่มคำสั่ง 5 ชุดที่แย่งความเด่นกัน ทำให้เห็นรายการคลิปทันทีโดยไม่ต้องเลื่อนจอลง และยังคงเครื่องมือขั้นสูงครบทุกตัวโดยไม่ตัดฟีเจอร์ใดทิ้ง

## 2. User Experience & Visual Design

### Key User Flows (Before ➔ After Hierarchy)

1. **ส่วนหัวหน้าคลังคลิปหลัก (Header & Slim KPI Strip)**:
   - *แถวบน (Single-Line Header)*: ด้านซ้ายแสดงชื่อ **`คลังคลิปหลัก (Master Archive)`** แบบกระชับ (ตัดย่อหน้าอธิบายยาวออก) ด้านขวาแสดงเฉพาะสวิตช์หลัก **`[ มุมมองรายตอน (N) | ชั้นวางรายการ 5 อันดับ (M) ]`** คู่กับปุ่มเมนู **`[ จัดการคลัง ▾ ]`** (ที่มีรายการครบทั้ง 3 อย่าง: จัดหมวดคลังคลิป, ปรับ Template สุดฮา! พร้อมตัวนับคงค้าง, และ เพิ่มคลังคลิปสู่ Kontent OS)
   - *แถวล่าง (Slim KPI Row)*: การ์ดสถิติ 4 ใบ (`คลังคลิปทั้งหมด`, `อัตราใช้ฟุตเทจ`, `ผลิตสูงสุด`, `ผลิตน้อยสุด`) ปรับขนาดให้บางลง อ่านตัวเลขและชื่อรายการได้ชัดในพริบตา

2. **แถบเลือกหมวดคลังคลิปและรายการ 5 อันดับ (Compact Series Navigation)**:
   - ลดระยะห่างและความหนาของแถวเลือก **1. หมวดคลังคลิป** และ **2. รายการ 5 อันดับ** ให้กะทัดรัด คงปุ่มเรียงลำดับ ช่องค้นหารายการ และปุ่มกางดูทุกรายการไว้ตามเดิม แต่ลดข้อความบรรยายที่ซ้ำซ้อน

3. **แถบค้นหาเดียวที่รวมตัวช่วยทั้งหมด (Unified Search & Drawer Triggers)**:
   - ถอดแถบพับขนาดใหญ่ 2 อันที่เคยคั่นกลางหน้าออก (`จัดอันดับรายการ 5 อันดับ...` และ `ค้นหาคลิปหลักจากแท็กฟุตเทจย่อย 3 ชั้น...`)
   - วางปุ่มเปิดใช้ 3 ตัวเรียงเป็นระเบียบต่อจากช่องค้นหาในแถวเดียว:
     - **`สรุปรายการ (55)`**: คลิกเพื่อกางตารางเปรียบเทียบและอัตราใช้ฟุตเทจของทุกรายการ
     - **`แท็ก 3 ชั้น`**: คลิกเพื่อกางตัวเลือกแท็กฟุตเทจ Tier 1–3 (พร้อมตัวนับจำนวนแท็กที่กำลังกรอง)
     - **`ตัวกรองย่อย`**: คลิกเพื่อกางตัวกรองรูปแบบตอนและหมวดย่อย
   - กรณีอยู่ในแท็บ **ชั้นวางรายการ 5 อันดับ** ยังคงมีปุ่มลัดเปิด **`สรุปรายการ (55)`** ให้เรียกดูตารางเปรียบเทียบได้เช่นเดียวกัน

### Visual Identity & Theme

- **Aesthetic Direction**: **Light Pastel Earth-Tone Enterprise** — พื้นผิวครีมอบอุ่น `#FDFBF7` / `#FAF7F2` ขอบบาง 1px `#E8DFD3` แยกบทบาทปุ่มด้วยโทนพาสเทลอ่อนไม่ฉูดฉาด
- **Visual Restraint**:
  - มีเพียง **1 Focal Switcher** ที่ส่วนหัว (`มุมมองรายตอน` ⇄ `ชั้นวางรายการ`) และ **1 Unified Menu** (`จัดการคลัง`) ลดการวางปุ่มขนาดเท่ากัน 5 ปุ่มแข่งกันบนหัวหน้า
  - ตัวเลขทั้งหมดใช้ `font-mono tabular-nums` และปุ่มทุกตัวใช้ `whitespace-nowrap` เพื่อไม่ให้ตัดบรรทัดเสียทรงบนจอ Desktop และ Mobile

### Interactive Feedback & Responsive Layout

- **Menu Interaction**: เมนู `จัดการคลัง` รองรับการคลิกปิดเมื่อกดนอกพื้นที่ (Backdrop Click) และแสดงจุดหรือตัวเลขแจ้งเตือนสีอุ่นเมื่อมีตอนที่ต้องปรับ Template
- **Contextual Expand**: แผงตารางสรุป 55 รายการ และแผงแท็ก 3 ชั้น จะเปิด/ปิดด้วย Motion Transition แบบนุ่มนวลและเฉพาะจุดเมื่อกดเรียกใช้จากแถบค้นหา ไม่กินพื้นที่หน้าจอเมื่อไม่ได้ใช้งาน

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: ใช้ปุ่มเมนู `จัดการคลัง` แบบเดียวกันทั้ง Desktop และ Mobile**
  - *Chosen Approach*: ยุบปุ่มเครื่องมือ 3 ตัวบน Desktop เข้าในเมนูดรอปดาวน์ `จัดการคลัง` เหมือนกับเวอร์ชัน Mobile ที่ใช้งานอยู่แล้ว
  - *Why*: ผู้ใช้จะได้ไม่ต้องจดจำหรือสับสนกับปุ่มเครื่องมือซ่อมชื่อ/จัดหมวด/ซิงก์ภายนอกที่ไม่ได้ใช้ทุกวินาที ทำให้พื้นที่ส่วนหัวเหลือเฉพาะการสลับมุมมองหลักกับเมนูเครื่องมือ
  - *Alternatives Considered*: เหลือปุ่ม Kontent OS ไว้ด้านนอก 1 ปุ่ม — ยังคงทำให้มุมขวาบนมีปุ่มหลายระดับซ้อนอยู่

- **Decision 2: ย้าย Drawer สรุป 55 รายการ และแท็ก 3 ชั้น เข้าไปเปิดจากแถบค้นหาเดียว**
  - *Chosen Approach*: เปลี่ยนจากการวางแถบหัวข้อกล่องใหญ่ 2 กล่องคั่นกลางหน้า มาเป็นการคุมสถานะเปิด/ปิดจากปุ่มในแถบค้นหาหลัก แล้วค่อยกางเนื้อหา Drawer ด้านล่างเมื่อกด
  - *Why*: ลดจำนวนกล่องข้อความอธิบายที่คล้ายกันลงได้ทันที 2 กล่องเต็ม และนำตำแหน่งการใช้งานฟีเจอร์กรองแท็กมาอยู่ชิดกับช่องค้นหาที่ผู้ใช้มองหาเป็นจุดแรก
  - *Alternatives Considered*: แปลงเป็น Modal แยก — อาจทำให้ผู้ใช้เทียบผลลัพธ์การกรองแท็กกับรายการคลิปแบบเรียลไทม์ได้ไม่สะดวกเท่ากางบนหน้าเดิม

### Data Model & State

- ไม่มีการแก้ไขโครงสร้างข้อมูล Episode หรือการคำนวณ Metric ใดๆ (`useMasterArchiveMetrics`, `useMasterArchiveFilter`)
- เพิ่ม State ระดับ View สำหรับการเปิด/ปิดแผงช่วย 2 ตัว (`isRankingSummaryOpen` และ `isThreeTierDrawerOpen`) แทน State ที่เคยฝังแยกอยู่ใน Component ย่อยของแบนเนอร์เดิม

### Interactive Component & State Mapping

- **Header Action Menu**: ปุ่ม `จัดการคลัง` เปิด/ปิดเมนูดรอปดาวน์พร้อม Trigger Callback เดิมครบทั้ง 3 ตัว (`onOpenManageCategories`, `onOpenTemplateStandardizer`, `onOpenSupabaseSync`)
- **Unified Toolbar Triggers**:
  - กดปุ่ม `สรุปรายการ (N)` สลับค่า `isRankingSummaryOpen` เพื่อเปิด/ปิดตารางสรุป 55 รายการ (และเมื่ออยู่ในแท็บ `SERIES_SHELF` จะมีแถบปุ่มสลับเปิดตารางนี้ได้เช่นกัน)
  - กดปุ่ม `แท็ก 3 ชั้น` สลับค่า `isThreeTierDrawerOpen` เพื่อเปิด/ปิดตัวกรองแท็ก Tier 1–3 โดยยังคงแถบแสดงแท็กที่ถูกเลือกไว้เสมอเมื่อมีการเลือกแท็กค้างอยู่
- **Quality Banner Preservation**: แบนเนอร์แจ้งเตือนคุณภาพตอน (`EpisodeQualityWarningBanner`) ยังคงแสดงตามเดิมเฉพาะเมื่อพบตอนที่มีปัญหา เพื่อให้ทีมงานแก้ข้อมูลที่ขาดได้ทันที
