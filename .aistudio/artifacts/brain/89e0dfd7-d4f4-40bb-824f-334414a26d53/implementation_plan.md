# แผนการติดตั้งโลโก้ 'เรียงเรื่องลั่น' บนแท็บเบราว์เซอร์และแบรนด์ของระบบ

แผนงานสำหรับนำรูปภาพโลโก้ประจำช่อง "เรียงเรื่องลั่น" มาติดตั้งเป็น Favicon บนแท็บเบราว์เซอร์แทนรูปโลก พร้อมอัปเดตชื่อแท็บบนเบราว์เซอร์ และนำไปแสดงผลเป็นแบรนด์ไอคอนหลักบน Sidebar (เดสก์ท็อป) และ Mobile Navigation (มือถือ) ให้สอดคล้องกันทั่วทั้งระบบ

---

## สรุปการตัดสินใจจากผู้ใช้ (Confirmed Decisions)

> [!IMPORTANT]
> **การตัดสินใจที่ยืนยันแล้วจากแบบสอบถาม:**
> 1. **ขอบเขตการแสดงผล**: นำโลโก้ใหม่ไปใช้ทั้งเป็น **Favicon บนแท็บเบราว์เซอร์** และ **โลโก้หลักในเมนูด้านข้าง (Sidebar) รวมถึงแถบเมนูมือถือ (Mobile Drawer)**
> 2. **ชื่อบนแท็บเบราว์เซอร์ (`<title>`)**: ปรับเปลี่ยนเป็น **`เรียงเรื่องลั่น - ระบบคลังและจัดคลิป 5 อันดับ`** พร้อมอัปเดต OpenGraph (`og:title`, `og:image`) และ Twitter card ให้แสดงรูปโลโก้และชื่อใหม่อย่างสวยงาม

---

## 1. ภาพรวมและเป้าหมาย (Overview & Core Concept)

- **สิ่งที่จะปรับปรุง**:
  - เปลี่ยนไอคอน Favicon เดิม (`/favicon.svg`) ใน `index.html` เป็นภาพโลโก้ช่อง `/assets/aistudio/Logo_Funny__b4902753.png` พร้อมรองรับ `icon`, `apple-touch-icon`, และ `shortcut icon`
  - ปรับชื่อแท็บเบราว์เซอร์ (`<title>`) ให้กระชับ สละสลวย และตรงตัวตามที่เลือก: `เรียงเรื่องลั่น - ระบบคลังและจัดคลิป 5 อันดับ`
  - อัปเดต OpenGraph meta tags ให้แชร์ลิงก์แล้วมีภาพปกและชื่อที่ถูกต้อง
  - อัปเดตส่วนหัวของ Sidebar (Desktop) และ Mobile Navigation Drawer (Mobile) ให้แสดงภาพโลโก้นี้แทนไอคอน SVG เดิม

## 2. ประสบการณ์ผู้ใช้และการออกแบบ (UX & Visual Design)

```
┌────────────────────────────────────────────────────────────────────────┐
│ [Logo] เรียงเรื่องลั่น - ระบบคลังและจัดคลิป 5 อันดับ          [—] [口] [X]│  <-- Browser Tab
├────────────────────────────────────────────────────────────────────────┤
│  ┌───────────┐                                                         │
│  │ (  Logo ) │  เรียงเรื่องลั่น                                         │  <-- Desktop Sidebar
│  │  [IMAGE]  │  Footage Utilization CMS                                │
│  └───────────┘                                                         │
│  ───────────────────────────────────────────────────────────────────── │
│  [+] คลังคลิป  |  [#] สายพาน E2E  |  [★] จัด 5 อันดับ                  │
└────────────────────────────────────────────────────────────────────────┘
```

- **แท็บเบราว์เซอร์**: เมื่อเปิดหน้าต่าง จะไม่เห็นไอคอนลูกโลกหรือไอคอนเริ่มต้นอีกต่อไป แต่จะเห็นโลโก้การ์ตูนช่อง "เรียงเรื่องลั่น" ชัดเจน พร้อมชื่อระบบ
- **Sidebar & Mobile Drawer**: ตัวกรอบแสดงไอคอนขนาด 40x40px (w-10 h-10) จะแสดงภาพการ์ตูนคมชัด ไร้รอยต่อ และมีแอนิเมชัน Hover นุ่มนวลตามดีไซน์เดิม

## 3. รายละเอียดการดำเนินการทางเทคนิค (Technical Steps)

```
[public/assets/aistudio/Logo_Funny__b4902753.png]
       │
       ├─► index.html (Favicon, Apple Touch Icon, og:image, <title>)
       │
       ├─► src/components/layout/Sidebar.tsx (Brand Avatar)
       │
       └─► src/components/layout/MobileNavigation.tsx (Mobile Drawer Brand Avatar)
```

1. **`index.html`**:
   - อัปเดต `<title>` เป็น `เรียงเรื่องลั่น - ระบบคลังและจัดคลิป 5 อันดับ`
   - ปรับ `<link rel="icon">` ให้ชี้ไปยัง `/assets/aistudio/Logo_Funny__b4902753.png`
   - ปรับ `<link rel="apple-touch-icon">` ให้ชี้ไปยัง `/assets/aistudio/Logo_Funny__b4902753.png`
   - เพิ่ม/อัปเดต `<meta property="og:image" content="/assets/aistudio/Logo_Funny__b4902753.png" />`
   - อัปเดต `og:title` และ `twitter:title` ให้ตรงกับชื่อใหม่

2. **`src/components/layout/Sidebar.tsx`**:
   - เปลี่ยนแท็ก `<img src="/favicon.svg" ... />` เป็น `<img src="/assets/aistudio/Logo_Funny__b4902753.png" ... />`
   - ปรับสไตล์กรอบให้พอดีกับภาพวงกลมของโลโก้

3. **`src/components/layout/MobileNavigation.tsx`**:
   - เปลี่ยนแท็ก `<img src="/favicon.svg" ... />` ใน Drawer Header เป็น `<img src="/assets/aistudio/Logo_Funny__b4902753.png" ... />`
