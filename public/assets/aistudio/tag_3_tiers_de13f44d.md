# คลังข้อตกลงระบบ Tag 3 Tiers (Tagging Rules & Data Dictionary)
**สำหรับทีมงานและ AI (Prompt Knowledge Base)**

เอกสารนี้คือแหล่งอ้างอิงหลัก (Source of Truth) สำหรับการติด Tag วิดีโอ เพื่อให้ทุกคนในทีมและ AI เข้าใจตรงกัน หากมีข้อสงสัยว่าคลิปไหนควรใส่ Tag อะไร ให้ยึดตามเอกสารนี้เป็นหลัก

---

## 🎯 เป้าหมายและบริบทของระบบ (Objective & Business Context)

**ลักษณะช่องของเรา:** เราทำช่องคอนเทนต์ประเภท **"จัดอันดับ 5 อันดับคลิปตลกสุดฮา"** ซึ่งมีความหลากหลายสูงมาก (ครอบคลุมทั้งคนดัง, ชาวบ้าน, อาชีพ, สัตว์, ข่าว, เหตุการณ์โซเชียล ฯลฯ)

**คำศัพท์ที่ต้องเข้าใจตรงกัน (Terminology):**
1. **ฟุตเทจ (Footage):** คลิปวิดีโอเหตุการณ์ตลก 1 เหตุการณ์ (เปรียบเสมือนวัตถุดิบ)
2. **คลิป (Clip):** วิดีโอตัวเต็ม (Final Product) ที่นำ "ฟุตเทจ" จำนวน 5 อัน มาจัดอันดับและมัดรวมกัน (เช่น คลิป "5 อันดับสัมภาษณ์ข่าวพูดผิดสุดฮา")

**ทำไมต้องใช้ระบบ Tag 3 ชั้น (Pain Point & Solution):**
*   **ปัญหาของระบบเก่า:** เดิมเราจัดเก็บฟุตเทจแบบ "โฟลเดอร์ซ้อนโฟลเดอร์" (เช่น `คนมีชื่อเสียง -> ดารา -> ชื่อคน`) ปรากฏว่า **ระบบพัง** เพราะคลิปตลก 1 อันมีหลายองค์ประกอบซ้อนทับกัน เช่น ฟุตเทจ "ดาราตลกไปให้สัมภาษณ์ข่าวแล้วพูดผิด" ถ้านำไปเก็บในโฟลเดอร์ 'ดารา' ก็จะหาไม่เจอตอนที่ต้องการทำคลิปจัดอันดับหมวด 'พูดผิด' หรือ 'สัมภาษณ์ข่าว'
*   **ทางแก้ (Tag 3 Tiers):** เราจึงเปลี่ยนมาใช้ระบบ "ป้ายกำกับ (Tags)" แบบ 3 ชั้นแทน เพื่อทลายกรอบโฟลเดอร์ ฟุตเทจ 1 อันสามารถมีได้หลาย Tag อย่างอิสระ เพื่อให้เวลาคิดหัวข้อจัดอันดับแปลกๆ (เช่น "5 อันดับชาวบ้าน + ช็อตฟีล + ตอนน้ำท่วม") ทีมงานสามารถกด Filter ดึงฟุตเทจมาประกอบร่างเป็น 1 คลิปได้อย่างรวดเร็ว

## 🛑 กฎเหล็กในการติด Tag (Tagging Rules)

1. **อิสระจากกัน:** ห้ามคิดแบบโฟลเดอร์ (เช่น "คนนี้เป็นดารา ต้องอยู่ในหมวดดาราเท่านั้น") Tag คือส่วนผสม 1 คลิปสามารถมี Tag จาก Tier 1, 2, และ 3 รวมกันได้
2. **ห้ามมีคำว่า "ฮา" หรือ "สุดฮา":** ช่องของเราคือช่องตลกอยู่แล้ว ทุกฟุตเทจคือความฮา ดังนั้นเราจะไม่เปลืองเนื้อที่ Tag ด้วยคำว่า `#ดาราฮาๆ` แต่จะใช้ `#ดารา` เพียวๆ
3. **อย่าสร้าง Tag ขยะ:** หากฟุตเทจไหนไม่มีจุดเด่นที่ตรงกับ Dictionary ด้านล่าง ให้เว้นว่างไว้ใน Tier นั้นๆ ห้ามมโนคำขึ้นมาเองเด็ดขาด
4. **ฟุตเทจ 1 คลิป = หลายบริบทได้:** เช่น คลิปสัมภาษณ์นักเรียนตอนน้ำท่วม แล้วนักเรียนพูดผิดช็อตฟีล สามารถใส่ Tier 2 เป็น `#สัมภาษณ์ข่าว #น้ำท่วม #พูดผิด #ช็อตฟีล` ได้เลยในเซลล์เดียว
5. **ถ้าไม่แน่ใจ:** ให้ถามเข้ามาในแชท (หรือสอบถามหัวหน้าทีม) อย่าเพิ่งเดาเอง

## 🗂️ Tier 1: มิติปลายทาง (หมวดหมู่กว้าง)
**จุดประสงค์:** เพื่อบอกว่า "ฟุตเทจนี้คือเรื่องราวของวงการไหน หรือสิ่งมีชีวิตประเภทใด?"

| ชื่อ Tag (Tier 1) | ความหมายและบริบทที่ใช้ (Definition) |
| :--- | :--- |
| `#คนมีชื่อเสียง` | คนที่มีคนรู้จักเป็นวงกว้าง (เช่น ดารา, ศิลปิน, เน็ตไอดอล, อินฟลูเอนเซอร์, YouTuber, Streamer) ถ้าเป็นคนกลุ่มนี้ให้ใส่ Tag นี้เสมอ |
| `#วิถีชาวบ้าน` | เหตุการณ์ของคนธรรมดาทั่วไปที่ไม่ได้มีชื่อเสียง (เช่น ลุงป้าอาวโส, วัยรุ่น, ครอบครัว, เพื่อนฝูง, ชาวบ้านตามท้องถนน) |
| `#อาชีพ` | ฟุตเทจที่จุดเด่นอยู่ที่ "อาชีพ" ของคนในคลิป (เช่น ตำรวจ, ทหาร, นักเรียน, ครู, กู้ภัย, รปภ., คอลเซ็นเตอร์) |
| `#สัตว์โลก` | ฟุตเทจที่สิ่งมีชีวิตอื่นที่ไม่ใช่คนเป็นตัวเอกสร้างความฮา (เช่น หมา, ลิง, ปลา, หมี) |
| `#สื่อและบันเทิง` | ฟุตเทจที่ตัดมาจากสื่อกระแสหลัก (เช่น ฉากในหนัง, รายการทีวี, การแข่งขันกีฬา) |
| `#ความเชื่อและลี้ลับ` | ฟุตเทจที่เกี่ยวข้องกับศาสนา สิ่งศักดิ์สิทธิ์ ความเชื่อส่วนบุคคล หรือเรื่องผี (เช่น พระ, เณร, ร่างทรง, รายการผี) |
| `#ทั่วไป` | หมวดหมู่กลางๆ สำหรับของรอบตัว (เช่น อาหาร, ยานพาหนะ) |

*(หมายเหตุ: ในระบบฐานข้อมูล คำที่ทีมงานพิมพ์มาอย่าง `#คนดัง`, `#ยูทูปเบอร์`, `#ดารา` จะถูกอนุโลมและจัดให้อยู่ในกลุ่ม `#คนมีชื่อเสียง` ตามโครงสร้าง Data Dictionary ของเรา)*

## 🎬 Tier 2: บริบทและสไตล์คลิป
**จุดประสงค์:** เพื่อบอกว่า "ฟุตเทจนี้เกิดเหตุการณ์อะไรขึ้น หรือถูกถ่ายทำ/นำเสนอออกมาในรูปแบบไหน?"

### กลุ่ม A: สถานการณ์ / อาการ (เกิดอะไรขึ้นกับคนในคลิป)
| ชื่อ Tag | ความหมายและบริบทที่ใช้ (Definition) |
| :--- | :--- |
| `#พูดผิด` | คลิปที่มีการพูดคำผิด เพี้ยน ติดอ่าง หรือเรียบเรียงประโยคผิดจนเกิดความฮา |
| `#ช็อตฟีล` | สถานการณ์ที่โดนหักมุม โดนสวนกลับ หรือเบรกอารมณ์กะทันหันจนหน้าเหวอ |
| `#หัวร้อน` | อาการโกรธ โมโห ฟาดงวงฟาดงา (ที่ดูแล้วตลก) |
| `#ทะเลาะวิวาท` | การเถียงกัน หรือมีปากเสียงกัน (ในบริบทที่ดูแล้วตลกหรือเป็นไวรัล) |
| `#ผีเข้า` | อาการหรือสถานการณ์ที่อ้างว่าถูกผีหรือสิ่งลี้ลับสิงร่าง (ไม่ว่าจะจริงหรือแกล้งทำ) |
| `#แพ้เสียงในหัว` | อาการหลุดหัวเราะ หรือทำอะไรแปลกๆ เพราะทนเสียงสั่งการ (จากรายการ/เพื่อน) ไม่ได้ |
| `#คนเมา` / `#คนบ้า` | อาการมึนเมา หรือพฤติกรรมที่ดูไม่ปกติ (ใช้เฉพาะเมื่อเป็นพอยต์หลักของความฮา) |

### กลุ่ม B: เหตุการณ์ / เทศกาล (เกิดขึ้นในสภาพแวดล้อมไหน)
| ชื่อ Tag | ความหมายและบริบทที่ใช้ (Definition) |
| :--- | :--- |
| `#น้ำท่วม` | เหตุการณ์ที่เกิดขึ้นในขณะที่น้ำท่วม (เช่น พายเรือล้ม, สัมภาษณ์ตอนน้ำท่วม) |
| `#เรียนออนไลน์` | เหตุการณ์ที่เกิดขึ้นระหว่างการเรียนผ่าน Zoom/Meet |
| `#ซื้อของ` / `#ขายของ` | พฤติกรรมการซื้อขายสินค้า (เช่น แม่ค้าไลฟ์สดด่าลูกค้า) |
| `#โควิด` | เหตุการณ์ที่บริบทหลักคือช่วงโควิดระบาด (เช่น การใส่แมสก์, กักตัว) |
| `#สงกรานต์` / `#งานวัด` | เหตุการณ์ที่เกิดขึ้นในเทศกาลนั้นๆ |

### กลุ่ม C: วิธีการนำเสนอ (ทรงคลิปเป็นแบบไหน)
| ชื่อ Tag | ความหมายและบริบทที่ใช้ (Definition) |
| :--- | :--- |
| `#สัมภาษณ์ข่าว` | คลิปที่มีนักข่าวถือไมค์จ่อปาก หรือเป็นการให้สัมภาษณ์สื่อ |
| `#ไลฟ์สด` | คลิปที่ตัดมาจากการ Live Streaming (อ่านคอมเมนต์ไหลๆ, สตรีมเกม) |
| `#อ่านเมนต์` | คลิปที่ตั้งใจตอบคำถาม หรืออ่านคอมเมนต์จากชาวเน็ตมาเป็นประเด็นหลัก |
| `#พากย์เสียง` / `#พากย์บอล` | คลิปที่มีเสียงคนอื่นพากย์ทับลงไปในวิดีโอ (นรกส่งมาพากย์) |
| `#กล้องวงจรปิด` | ภาพที่มาจากกล้อง CCTV มุมสูง (มักเป็นเหตุการณ์ลื่นล้ม หรืออุบัติเหตุฮาๆ) |
| `#คอสเพลย์` | การแต่งตัวเลียนแบบตัวละครหรือสิ่งต่างๆ (เช่น ใส่ชุดสไปเดอร์แมนมาขายพวงมาลัย) |
| `#ล้อเลียน` | การแสดงที่ตั้งใจก๊อปปี้คาแรคเตอร์คนอื่นมาล้อ (เช่น แจ๊สล้อเลียน) |
| `#ร้องเพลง` / `#เต้น` | คลิปที่กิจกรรมหลักคือการร้องเพลงหรือเต้น (ร้องเพี้ยน, เต้นหลุดโลก) |

### กลุ่ม D: ความขลัง (ความพิเศษของฟุตเทจ)
| ชื่อ Tag | ความหมายและบริบทที่ใช้ (Definition) |
| :--- | :--- |
| `#คลิปในตำนาน` | คลิปที่ดังมากๆ คนไทยรู้จักกันดี (ระดับตำนาน) |
| `#มีมตลก` / `#มีม` | คลิปสั้นๆ หรือวลีฮิตที่ถูกเอามาใช้เป็น Meme ตัดต่อบ่อยๆ |
| `#Ai` | คลิปที่ถูกสร้างหรือดัดแปลงโดย AI (ไม่ว่าจะภาพหรือเสียง) |

## 👤 Tier 3: เฉพาะเจาะจง (ชื่อบุคคล หรือ ชื่อรายการ)
**จุดประสงค์:** เพื่อระบุตัวตน (Entity) ไปเลยว่านี่คือใคร หรือรายการอะไร (ไม่ต้องสนว่าเขาจะเป็นดาราหรือชาวบ้าน)

### กฎของ Tier 3:
1. **ใช้ชื่อที่คนเรียกติดปาก:** ไม่ต้องใส่ยศหรือนามสกุลยาวๆ (เช่น ใช้ `#น้าค่อม` ไม่ต้องใช้ `#อาคม ปรีดากุล`)
2. **ใส่ได้หลายคน:** ถ้าในคลิปมีน้าค่อมยืนคุยกับแจ๊ส ให้ใส่ทั้ง `#น้าค่อม` และ `#แจ๊ส` (ไม่ต้องสร้างแท็กใหม่ว่า `#แจ๊สน้าค่อม`)
3. **ชื่อรายการ:** ถ้ารู้ว่าเป็นคลิปจากรายการดัง ให้ใส่ชื่อรายการไปด้วยเสมอ

### ตัวอย่างรายชื่อ (Entity List) ที่ใช้บ่อย:
*   **สายตลก/ดารา:** `#พี่เสก`, `#แจ๊ส`, `#น้าค่อม`, `#โก๊ะตี๋`, `#โหน่ง`, `#เท่ง`, `#หม่ำ`, `#พี่โจ๊ก`, `#ตุ๊กกี้`
*   **สายอินฟลู/ไวรัล:** `#แจ๊กแป๊ปโฮ`, `#เซียนหรั่ง`, `#อาจารย์แดง`, `#หมอปลา`, `#พาวเว่อร์พัฟเกย์`, `#เอกสายเต๊าะ`, `#แม่สิตา`, `#ปู่องค์ดำ`, `#น้องหญิง`, `#ฟาโรส`, `#แก๊บโบ๋`, `#บาสบิวโบว์`, `#ลีน่าจัง`, `#หนูรัตน์`
*   **ชื่อรายการ/ผลงาน:** `#โหนกระแส`, `#เดอะโกสเรดิโอ`, `#เดอะช็อค`, `#คนอวดผี`, `#หอแต๋วแตก`, `#ตลกหกฉาก`, `#ถกไม่เถียง`, `#ฟ้ามีตา`, `#ชิงร้อยชิงล้าน`, `#ก็มาดิคร้าบ`
